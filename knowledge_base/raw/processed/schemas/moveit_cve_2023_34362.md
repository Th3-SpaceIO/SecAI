# Writeup: Exploiting CVE-2023-34362 (MOVEit Transfer)

## Vulnerability Summary
CVE-2023-34362 is a SQL injection vulnerability in the MOVEit Transfer web application that could allow an unauthenticated attacker to gain access to MOVEit Transfer's database.

## Technical Details
The vulnerability exists in the `guestaccess.aspx` endpoint. By crafting a specific header, an attacker can manipulate the SQL query used to validate session information.

## Exploitation in the Wild
This vulnerability was used by the Cl0p ransomware group for mass data exfiltration. The group used a custom webshell named `LEMURLOOT` to interact with the database and upload files.
